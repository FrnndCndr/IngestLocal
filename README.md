# IngestLocal

**IngestLocal** es una herramienta inspirada en [gitingest](https://gitingest.com) pero diseñada para funcionar de manera **local**, sin depender de plataformas como GitHub y sin limitaciones en repositorios privados.

## ✨ Características
- Selecciona de forma visual los archivos y carpetas de tu proyecto que deseas exportar.
- Excluye automáticamente archivos y carpetas sensibles o innecesarios (.env, node_modules, binarios, etc.).
- Genera un archivo `.txt` con:
  - La estructura del directorio.
  - El contenido de los archivos seleccionados.
- Compatible con **GitHub**, **GitLab**, **Azure DevOps** o cualquier repositorio clonado localmente.
- Sin dependencias externas ni conexión a Internet requerida.
